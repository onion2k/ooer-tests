# Codex Project Instructions

This project uses a Playwright MCP server for browser automation.
Use the configured MCP server ("playwright") for any web automation tasks
instead of attempting to run Playwright locally.

## Tech Stack
- TypeScript frontend
- Node.js backend
- Playwright for E2E tests

## Rules
- Prefer VS Code tasks for local builds
- When suggesting tests, use Playwright syntax
- Format code with Prettier (`npm run format`)
